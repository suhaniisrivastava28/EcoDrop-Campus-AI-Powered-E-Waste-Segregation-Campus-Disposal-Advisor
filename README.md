# 🌱 EcoDrop Campus: AI-Powered E-Waste Ecosystem (UN SDG 12)

> **EcoDrop Campus transforms university e-waste management through AI hazard scanning, an interactive map of 7 specialized collection bins, and cafeteria Eco-Credit rewards to divert toxic materials and champion responsible consumption (SDG 12).**

🌐 **Live Demo:** [https://ecodrop-campus.vercel.app](https://ecodrop-campus.vercel.app)

---

## 🎯 Project Overview
EcoDrop Campus is an AI-powered smart segregation web application designed for university campuses to tackle rapid electronic waste accumulation and hazardous disposal. Developed as part of the **1M1B Virtual Internship Portfolio** in collaboration with **IBM SkillsBuild & AICTE**.

---

## ✨ Key Features

### 1. 🤖 AI Advisor & Multimodal Hazard Scanner
- **Multimodal Camera & Upload Scan**: Upload or capture photos of electronics (batteries, cables, vapes, motherboards, headphones) with instant component recognition.
- **Toxicity & Chemical Breakdown**: Identifies hazardous substances (Lithium-ion fire risks, Mercury traces, Lead, Cadmium) and details proper handling.
- **Eco-Credits Vouchers**: Generates unique cafeteria redemption voucher codes with each verified inquiry.

### 2. 🗺️ Geospatial Smart Zone Map (Digital Twin Layer)
- **Minimalist Schematic Design**: Inspired by EcoSync OS geospatial aesthetics with warm sand & latte architectural canvas.
- **7 Specialized Campus Bins**:
  1. *Bin Alpha*: Student Quad Hub (Cables & Cords)
  2. *Bin Beta*: Science Block East (Batteries & Alkaline Cells)
  3. *Hazard-X Bay*: Tech Support Rm 204 (Critical Fire-Safe Containment)
  4. *Bin Delta*: Main Library Hub (Smartphones & Tablets)
  5. *Bin Gamma*: Engineering Workshop (PCBs & Heavy Motors)
  6. *Bin Epsilon*: Student Activity Center (Audio & Wearables)
  7. *Bin Eta*: Hostel Quadrangle (Dorm Electricals)
- **Dynamic Auto-Dodging Telemetry Card**: Real-time ultrasonic fill volume, temperature, and collection yields that intelligently dodge across the screen to never obstruct selected bins.
- **Simulate Walk Route**: Animated pedestrian route guidance from the Quad center.

### 3. 🏆 Campus Impact & Department Leaderboard
- **Live Diversion Metrics**: Real-time counters for e-waste diverted (kg), carbon emissions prevented, and toxic heavy metal containment.
- **Inter-Department Competition**: Live ranking of campus schools (Computer Science, Economics, Electronics, Humanities, Management) with impact boost simulations.
- **Eco-Warrior Badges**: Unlockable sustainability milestones.

### 4. 📊 Admin Telemetry & Predictive Analytics
- **Bi-Weekly Inflow Barchart**: Dual-zone colored predictive exam period influx forecasting.
- **Bin Sensor Health Grid**: Live telemetry monitoring temperature, ultrasonic fill %, and maintenance dispatch.

### 5. 💳 Eco-Credits Cafeteria Rewards
- Starting from **Level 1 (0 XP)** with progression milestones.
- Redeemable vouchers for campus cafeterias, coffee kiosks, and printing stations.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v16 or higher)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/suhaniisrivastava28/EcoDrop-Campus-AI-Powered-E-Waste-Segregation-Campus-Disposal-Advisor.git

# Navigate into the project folder
cd EcoDrop-Campus-AI-Powered-E-Waste-Segregation-Campus-Disposal-Advisor

# Install dependencies
npm install

# Start the local development server
npm run dev
```

The application runs on `http://localhost:5009`.
